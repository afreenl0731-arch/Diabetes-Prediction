# Diabetes Prediction System Using Machine Learning

## Project Description
Developed a Diabetes Prediction System using Python and Machine Learning with the Logistic Regression algorithm. Performed data preprocessing, feature scaling, model training, and evaluation. Created an interactive Streamlit web application to predict diabetes based on patient health parameters.

## Technologies Used
- Python
- Machine Learning
- Logistic Regression
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Matplotlib

## Project Features
- Data preprocessing and analysis
- Model training and testing
- Feature scaling using StandardScaler
- Diabetes prediction
- Interactive Streamlit web application

## Dataset
The project uses a diabetes dataset containing medical information such as glucose, blood pressure, BMI, insulin, age, and other health parameters.

## Installation

Install the required libraries:

```bash
pip install pandas numpy scikit-learn matplotlib streamlit
```

## Run the Project

```bash
streamlit run app.py
```

## Project Objective
The main objective is to demonstrate how Machine Learning can be used to analyze medical data and predict the possibility of diabetes.
